# 달빛약속: 코딩 학습 경험 실험실

```
약속, (음식)을 (사람)과 먹기
    "맛있는 {음식}, {사람}의 입으로 모두 들어갑니다." 보여주기

먹을_음식 = "유부초밥"
먹일_사람 = "현수"

먹을_음식을 먹일_사람과 먹기
```

```
약속, 예매하기(차종, 좌석?)
    만약 좌석 == 비어있음 이면
        차종 + " / 좌석 없음" 보여주기
    아니면
        차종 + " / " + 좌석 보여주기

예매하기("KTX")

예매하기
    좌석: "1A"
    차종: "새마을"
```

한글 프로그래밍 언어를 넘어, 낯섦이 실패로 이어지지 않을 수 있는 코딩 학습 환경을 실험합니다.

[온라인 데모](https://dalbit-yaksok.postica.app)에서 직접 사용할 수 있습니다.
